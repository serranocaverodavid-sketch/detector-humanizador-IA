# Detector de IA

La herramienta más avanzada para detectar y humanizar textos generados por inteligencia artificial.

## 🚀 Desplegar en Netlify

### Opción 1: Arrastrar y soltar
1. Ve a [app.netlify.com](https://app.netlify.com)
2. Inicia sesión o crea una cuenta
3. Arrastra la carpeta `detector-ia` completa a la zona de drop
4. ¡Listo! Tu web estará disponible en algo como `detector-ia.netlify.app`

### Opción 2: Desde GitHub
1. Sube esta carpeta a un repositorio de GitHub
2. En Netlify, haz clic en "New site from Git"
3. Conecta tu repositorio
4. Deja los campos vacíos (no necesita build)
5. Haz clic en "Deploy site"

## ✨ Características

- ✅ Detector de IA (ChatGPT, Gemini, Claude, Grok, etc.)
- ✅ Humanizador de texto con 3 opciones
- ✅ Banner de cookies RGPD compliant
- ✅ Diseño responsive
- ✅ Espacios para Google AdSense
- ✅ Páginas legales completas

## 🔧 Configuración de AdSense

Reemplaza `ca-pub-XXXXXXXXXXXXXXXX` en `index.html` con tu ID de AdSense real.

## 📝 Personalizar dominio

En Netlify:
1. Ve a "Domain settings"
2. Haz clic en "Add custom domain"
3. Escribe tu dominio personalizado (ej: `detector-ia.com`)

## 🌐 Ejemplo de URL

Después de desplegar, tu web estará en:
- `https://detector-ia.netlify.app` (o el nombre que elijas)
